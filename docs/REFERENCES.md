# Resmî Referanslar

Proje geliştirilirken program terimleri ve öğrenme çıktıları tahmin edilmemeli; resmî kaynaklardan sürümlü biçimde alınmalıdır.

## Millî Eğitim Bakanlığı

- Türkiye Yüzyılı Maarif Modeli Okul Öncesi Öğretim Programı: https://tymm.meb.gov.tr/ogretim-programlari/ders/okul-oncesi
- Okul Öncesi Eğitim Programı PDF: https://tegm.meb.gov.tr/meb_iys_dosyalar/2024_09/20104013_2024programokuloncesionayli.pdf
- Öğrenme Kanıtları: https://tymm.meb.gov.tr/olcme-degerlendirme
- Öğrenme Çıktıları Çerçevesi: https://tymm.meb.gov.tr/ogrenme-ciktilari-cercevesi
- Program Okuryazarlığı Kılavuzları: https://tymm.meb.gov.tr/program-okuryazarligi-kilavuzlari

## Kaynak yönetimi kuralı

Resmî program verileri `MaarifReference.sourceVersion` alanıyla sürümlenmelidir. Kaynak güncellendiğinde eski eğitim yılı kayıtları geçmiş sürümle bağını korumalıdır.
