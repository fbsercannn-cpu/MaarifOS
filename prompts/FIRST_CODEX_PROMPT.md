# Codex’e Verilecek İlk Komut

Bu depodaki `PROJECT.md`, `AGENTS.md` ve `docs/` klasöründeki bütün belgeleri oku. Henüz özellik kodlamaya başlamadan önce proje için teknik temel kur.

İlk görev:

1. React + TypeScript + Vite tabanlı mobil öncelikli bir PWA oluştur.
2. TypeScript strict, lint, format, birim test ve uçtan uca test altyapısını kur.
3. `src/domains`, `src/infrastructure`, `src/shared`, `src/pages` yapısını oluştur.
4. IndexedDB için repository arayüzlerini ve ilk sürümlü veritabanı şemasını kur.
5. `AcademicYear`, `Classroom`, `Student`, `AttendanceRecord` ve `Observation` modellerini ekle.
6. Gerçek kişilere ait olmayan Türkçe demo verileri oluştur.
7. Alt menüde `Günüm`, `Çocuklar`, `Kayıt Ekle`, `Arşiv`, `Raporlar` bölümlerini hazırla.
8. Günüm ekranında çalışır bir yoklama kartı ve hızlı gözlem girişinin ilk sürümünü yap.
9. Uygulamanın internet kapalıyken açıldığını doğrulayan test veya açık test prosedürü ekle.
10. Basit JSON dışa aktarma ve geri yükleme iskeletini hazırla.

Sınırlar:
- OpenAI API veya başka bir yapay zekâ API’si ekleme.
- Yüz tanıma ekleme.
- Sunucu veya kullanıcı hesabı ekleme.
- Gerçek öğrenci verisi kullanma.
- Mimariyi tek dosyalık prototipe dönüştürme.

Çalışmaya başlamadan önce:
- Uygulama planını yaz.
- Kuracağın bağımlılıkları ve nedenlerini listele.
- Riskleri belirt.

Çalışma bittikten sonra:
- Çalıştırma komutlarını ver.
- Test sonuçlarını özetle.
- Mobil ve çevrimdışı kontrol listesini paylaş.
- Bir sonraki mantıklı görevi öner, fakat kendiliğinden yeni faza geçme.
